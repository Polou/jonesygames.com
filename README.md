# jonesygames.com

Site statique du studio Jonesy Games, servi par GitHub Pages sur `https://jonesygames.com`.

- `privacy/`, `en/privacy/` : politique de confidentialité (FR de référence, EN)
- `support/` : contact et procédure de suppression de compte (FR + EN `#en`)
- `app-ads.txt` : ligne AdMob à coller ici quand le compte AdMob existera
- `CNAME` : domaine personnalisé, ne pas supprimer

Modifier un fichier puis `git push` sur `main` : le site se met à jour en ~1 minute.
Toute modification de la politique de confidentialité doit aussi changer la date « Dernière mise à jour ».
